27.05.2025 - Рефакторинг репозитория

Water Delivery - это проект для доставки воды с backend и frontend частью.
Используемый стак технологий:
Backend - FastAPI, SQLite, MySQL. Frontend - Nuxt 3, Tailwind 4 css + daisy.ui + shadcn-nuxt.

Backend расположен в папках BackW и Backw_sqlite.
BackW - это папка с проектом backend с базой данных MySQL.
Backw_sqlite - это папка с проектом backend с базой данных SQLite.

Frontend расположен в папке FrontW.
